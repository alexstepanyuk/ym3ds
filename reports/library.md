# Полная библиотека, плейлисты и обложки — 08.10.2026

Убраны фиксированный массив и ограничение в 100 песен. Список ID выделяется
динамически; метаданные публикуются пакетами по 25. При выборе ещё не
загруженной песни запрашивается её пакет. После прерывания загрузки библиотеки
оставшиеся названия догружаются в простое. Песни с подтверждённым отсутствием
прав пропускаются; ещё не проверенные записи можно выбрать и загрузить.

Добавлены личные и понравившиеся плейлисты, включая владельцев чужих списков.
X открывает плейлисты; A открывает песни списка; B возвращает прежний список.
На экране плейлистов X или первая строка открывают «Мне нравится».

Обложки JPEG/PNG запрашиваются в размере 100×100, проверяются по размеру,
преобразуются в текстуру 128×128 ABGR и отображаются на верхнем экране.
Файл ограничен 512 КиБ, размеры — 512×512, ожидание — 8 секунд. Ошибка картинки
не останавливает запуск песни. В памяти хранится одна обложка; её ресурсами
GPU управляет только основной поток. Переключение библиотеки останавливает звук.

Проверки `tools/test-host.ps1` прошли: список из 2000 ID без обрезания,
пустые и некорректные ответы, маршруты плейлистов, 64-битные владельцы,
незагруженные и недоступные песни, допустимые HTTPS-адреса картинок,
PNG с четырьмя цветами (ориентация и ABGR), повреждённые изображения,
все прежние проверки MP3 и потокового чтения.

Полноценная сборка 3DS и живой API не проверялись. Дополнительная попытка
проверки синтаксиса с Zig и заголовками 3DS завершилась ошибкой драйвера
`FileNotFound`; её результат не считается подтверждением проверки API 3DS.
Большие ответы по-прежнему ограничены 2 МиБ и доступной памятью, с явной
ошибкой вместо скрытой обрезки списка. Обложки списка плейлистов, поиск,
альбомы и отдельный дисковый кэш изображений в этот этап не входят.
