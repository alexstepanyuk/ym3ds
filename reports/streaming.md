# Проверка воспроизведения во время загрузки

На компьютере проверен `current.mp3`: 11 001 600 отсчётов, 44 100 Гц,
стерео. `tools/test-host.ps1` выполняет проверки API и MP3 с активными assert.

Реальный MP3 поступает порциями по 4 КиБ через отдельный файловый дескриптор
записи. Декодер использует те же `mp3_stream_read` / `mp3_stream_seek`, что
плеер. Первые PCM получены до окончания загрузки, все PCM совпадают с полным
декодированием. Проверены ожидание, возврат к началу, отказ от перехода за
доступные данные, короткий хвост EOF, ошибка загрузки, отмена и остановка.

Этот тест использует управляемую подачу данных при ожидании, а не Wi-Fi или
NDSP. Конкурентная работа curl, SD и DSP на 3DS требует проверки на устройстве.
Сборка приложения для 3DS и запуск GitHub Actions не выполнялись.
