# YM3DS — прототип Яндекс Музыки для Nintendo 3DS

Первый этап переноса [YMPSP](https://github.com/amdray/yandex_music_psp).
Целевая консоль — обычная 3DS / 3DS XL / 2DS, по уточнению пользователя.
Это отдельное homebrew-приложение на C: сетевой протокол взят за основу из
PSP-клиента, интерфейс и звук написаны для libctru/citro2d/NDSP.

**Статус:** пользователь подтвердил воспроизведение на обычной 3DS.
Пользователь также подтвердил потоковую загрузку и управление A/R.
Полная библиотека, плейлисты и обложки проверены на компьютере;
эта новая версия ещё не собрана и не проверена на консоли.

## Что реализовано в коде

- Чтение OAuth-токена с SD и проверка `/account/status`.
- Все записи «Мне нравится» из ответа API, без ограничения в 100 треков.
  Память выделяется под список; названия и исполнители приходят пакетами по 25,
  каждый пакет сразу появляется на экране. Незагруженный выбранный трек
  получает метаданные перед запуском. Оставшиеся данные догружаются в простое.
- Личные и понравившиеся плейлисты, просмотр списка и запуск их треков.
- Обложка текущего трека 100×100 на верхнем экране (JPEG/PNG), загружается
  по HTTPS без OAuth. Таймаут картинки — 8 секунд; при ошибке остаётся значок
  пластинки и запуск музыки продолжается. Одновременно хранится одна обложка.
- Подписанный `/get-file-info` с MP3/raw, качеством `nq`/`hq` (192/320), как в YMPSP.
- HTTPS с проверкой сертификата и имени сервера; токен не передаётся CDN.
- Загрузка выбранного MP3 на SD одновременно с декодированием minimp3
  и вывод PCM через NDSP. Файл читается небольшими блоками, а не целиком в RAM.
- Два экрана, системный шрифт, выбор треков кнопками и касанием.
- Рабочий поток, отмена загрузки, пауза, остановка и корректный выход.

Звук запускается после накопления 64 КиБ (около 2,7 секунд музыки при
192 кбит/с); небольшой файл запускается после завершения загрузки.
Загрузчик пишет `cache/current.mp3.part`, плеер читает уже записанные данные.
При нехватке данных плеер ждёт продолжения загрузки; пауза не останавливает
скачивание. После закрытия обоих потоков полностью загруженный файл становится
`cache/current.mp3` и остаётся на SD; незавершённый файл удаляется.
На полосе трека серо-голубой участок показывает загрузку, жёлтый — проигрывание.
Процент загрузки доступен, когда сервер сообщает размер, иначе видны килобайты.
Лимит файла — 32 МиБ, ответа JSON — 2 МиБ.
Большая библиотека может упереться в лимит ответа JSON 2 МиБ или доступную
память. В этом случае отображается ошибка, список не обрезается до 100 песен.
После окончания песни автоматически запускается следующий доступный трек;
после последнего список начинается сначала. Стоп, выход, ручное переключение
и ошибки загрузки или декодирования отменяют автоматический переход.
Между песнями есть пауза на получение ссылки и буферизацию следующего MP3.
Короткое L/R переключает трек при отпускании. Удержание от 600 мс перематывает
на −/+10 секунд, повторяясь каждые 600 мс. Вперёд можно перейти только в уже
скачанную область. Перемотка приближённая: используется битрейт MP3, поэтому
для VBR возможна неточность времени. Очередь PCM сбрасывается с ожиданием DSP.
При закрытой крышке сон запрещён, подсветка отключается, интерфейс не рисуется;
сеть и звук продолжают работать. При открытии подсветка восстанавливается.
Эта функция требует проверки на консоли; поддержка фонового звука в HOME
не добавлена. В этом режиме консоль продолжает работать, а не спит.
При временном DNS-сбое или разрыве соединения выполняются до пяти повторов
с новой сессией curl. После ошибки при закрытой крышке повтор ждёт открытия.
Пауза и позиция сохраняются, пока идут попытки восстановления. MP3 запрашивается
с начала: существующий префикс сверяется побайтово и пропускается, дописывается
только хвост. Это требует дополнительного трафика. Несовпадение данных или
исчерпание попыток приводит к ошибке. Обновление истёкших CDN-ссылок пока не добавлено.
Нет поиска, «Моей волны» и входа по коду. Производительность
на обычной и New 3DS требует измерений.

## Сборка

Нужны официальный devkitPro с devkitARM и пакеты:

```sh
dkp-pacman -Syu 3ds-dev 3ds-curl 3ds-mbedtls 3ds-zlib
make -j2
```

В Windows команды выполняются в оболочке devkitPro MSYS2.
`DEVKITPRO` и `DEVKITARM` должны указывать на установленный SDK.
Результат — `ym3ds.3dsx` и `ym3ds.smdh` в корне проекта.
Для проверки в GitHub подготовлен `.github/workflows/build.yml`; он
запускается вручную через Actions → build → Run workflow.

После успешной сборки в PowerShell:

```powershell
./tools/package.ps1
```

Скрипт создаст `release/ym3ds-sd.zip` с пустым шаблоном токена.

## Установка и запуск

1. Нужна консоль с возможностью запуска homebrew и настроенным Wi-Fi.
2. Скопируйте содержимое `release/3ds` в `3ds` на SD.
3. Заполните `sd:/3ds/ym3ds/config/token.txt`:

   ```text
   YANDEX_TOKEN = "ваш OAuth-токен Яндекс Музыки"
   ```

4. Рядом в `config` должен находиться комплектный `cacert.pem`.
5. Нужен `sd:/3ds/dspfirm.cdc`. В Luma3DS: Rosalina → Miscellaneous options →
   Dump DSP firmware. Без firmware список может загружаться, но звук отключён.
6. Установите правильные дату и время консоли: они нужны TLS и подписи API.
7. Запустите `ym3ds.3dsx` через Homebrew Launcher.

Токен вводится локально; не отправляйте его в чат и не публикуйте.
Доступ к музыке определяется аккаунтом, подпиской и доступностью треков.
Актуальность неофициального API необходимо проверить на устройстве.

Управление: вверх/вниз — выбор, влево/вправо — по шесть записей,
**A** — запустить выбранный трек (в том числе заново, если он уже играет).
**Y** — пауза/продолжение текущего трека независимо от выделения в списке,
без повторного скачивания. При запуске песни выделение переходит к ней.
**R** — следующий доступный трек, **L** — предыдущий
по списку. После последнего — первый. **SELECT** открывает меню настроек:
битрейт 192/320 кбит/с, перемешивание для R/автоперехода и повтор одной песни;
повтор имеет приоритет над перемешиванием только при автоматическом переходе.
Короткие L/R переходят к другой песне даже при включённом повторе;
удержание перематывает по 10 секунд. В настройках ↑/↓ выбирают пункт,
←/→ или A меняют значение, SELECT или B закрывают меню.
Битрейт применяется со следующего запуска песни; Y продолжает управлять паузой.
**B** — остановить,
**X** — открыть экран плейлистов; на этом экране X загружает «Мне нравится»
заново. **A** на плейлисте открывает его песни; первая строка — «Мне нравится».
**B** на экране плейлистов возвращается к прежнему списку треков.
Открытие библиотеки останавливает текущую песню. **START** — выйти.
Касание строки запускает выбранный трек, когда рабочий поток свободен.

## Проверки без консоли

Переносимая часть парсинга и MP3-декодер проверяются на Windows с Zig:

```powershell
./tools/test-host.ps1 -Zig 'путь/к/zig.exe' -Mp3 'путь/к/тестовому.mp3'
```

Тесты проверяют некорректные токены, ID больше 32 бит, порядок метаданных,
недоступные треки, отказ от шифрованных/HTTP-ссылок, UTF-8 и совпадение
блочного и постепенно поступающего MP3 с декодированием целого файла,
старт до конца загрузки, ожидание данных, конец файла, ошибку и отмену,
список из 2000 песен, владельцев плейлистов, ссылки обложек, PNG и их цвета.
Эти проверки не заменяют
сборку под ARM и тест звука/сети на настоящей 3DS.

Следующий этап: по команде пользователя собрать `.3dsx` и проверить большую
библиотеку, личные/понравившиеся плейлисты и обложки на обычной 3DS.

Лицензии и происхождение кода: `LICENSE.upstream`, `THIRD_PARTY.md`, `vendor/`.
